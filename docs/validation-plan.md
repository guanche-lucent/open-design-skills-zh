## 先筛选，再决定数量

从附带正文的条目中筛选：检查引用 → 判断环境依赖 → 按常见任务分组 → 比较同类 → 确定本轮测试对象。没有固定八个名额。

仅简介、仅外链不进入本地完整技能测试。依赖 OpenDesign 专属接口的条目暂列适配队列。付费服务任务单独确定测试范围和成本。

## 每项记录

1. 技能 ID、原文件 SHA256、使用平台和版本、模型及日期。
2. 一个隔离测试项目；记录实际安装目录和外部依赖。
3. 固定输入和最简单调用方式，保留完整输入。
4. 实际产物与检查结果；页面任务检查桌面、移动端和主要交互。
5. 一次明确修改任务，以及修改后的产物和检查结果。
6. 限制、失败记录和重试情况；不隐藏未通过样例。

同类技能使用同一份输入。含代码或文件的场景不能只以“Agent 声称完成”为证据。

## 进入推荐区的条件

安装/发现、典型任务和修改任务均有证据；依赖、许可依据和输出格式写清楚；效果经过检查。只标记通过的环境与场景。

总路由单独测试四类请求：本地正文、仅简介、仅外链、OpenDesign 依赖。不能把“读取到文件”当作任务通过。
