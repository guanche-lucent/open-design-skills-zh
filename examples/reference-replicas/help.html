纸间是什么？

纸间是这个虚构案例中的个人笔记工具。此页面用于技能测试，不代表真实产品。

开始使用
怎样创建第一篇笔记？

点击「新建笔记」，输入标题后开始记录。测试规则中，内容会保存在当前设备。

开始使用
支持 Markdown 吗？

本案例支持 Markdown 标题、列表和链接。复杂语法需要以实际产品说明为准。

开始使用
可以离线写作吗？

测试设定允许离线编辑本地笔记。恢复网络不会自动公开内容。

开始使用
怎样给笔记分类？

为笔记添加标签，再在列表中按标签查看。同一篇笔记可以使用多个标签。

整理与导出
怎样搜索笔记？

在搜索框输入标题或正文中的关键词。测试范围只包含本地内容。

整理与导出
可以导出什么格式？

本案例提供 Markdown 文本导出。导出后请自行检查附件是否齐全。

整理与导出
导出后会删除原笔记吗？

不会。导出只创建副本，原笔记仍留在设备上。

整理与导出
笔记会自动公开吗？

不会。测试设定下，需要主动分享才会产生对外链接。

数据与隐私
可以撤销分享吗？

可以关闭分享链接。已经下载的副本无法通过关闭链接收回。

数据与隐私
怎样备份内容？

定期导出并保存到你选择的备份位置。请自行检查备份可读性。

数据与隐私
在哪里联系支持？

本页只提供虚构测试邮箱 help@example.invalid。它不会发送到真实客服。
