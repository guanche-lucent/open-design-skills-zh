# 按任务查找

[返回首页](../README.md) · [完整目录](../CATALOG.md)

以下为用途导航，**不是质量排名或已验证推荐**。同一任务的多个技能可能适用范围不同，先读正文和依赖再选择。

<a id="web"></a>
## 网页与界面

- [frontend-design](../skills/prototype/frontend-design/SKILL.md)：通用界面设计与实现；有 OpenDesign 条件集成说明，独立运行待测。
- [taste-skill](../skills/prototype/taste-skill/SKILL.md)：强调视觉取向和反模板化；需结合自己的技术约束。
- [web-clone](../skills/prototype/web-clone/SKILL.md)：网站复刻工作流，含浏览器和脚本；资源存在，但独立路径与环境仍待验证。

先说清楚：目标页面、用户、内容、框架，以及要新建还是改造已有项目。

<a id="polish"></a>
## 页面优化

- [impeccable-design-polish](../skills/prototype/impeccable-design-polish/SKILL.md)：已有页面的设计审查与打磨。
- [review-animations](../skills/prototype/review-animations/SKILL.md)：检查动效，附带 STANDARDS.md。
- `design-review` 当前仅简介，完整实现需要从其上游获取；不要误认为已经安装。

输入应包含现有代码或可检查的页面；验收需要修改前后对比。

<a id="content"></a>
## 图文内容

- [card-xiaohongshu](../skills/prototype/card-xiaohongshu/SKILL.md)：以 HTML 卡片版式为起点；发布图片还涉及渲染与截图。
- [article-magazine](../skills/prototype/article-magazine/SKILL.md)：杂志式长文排版。
- [poster-hero](../skills/prototype/poster-hero/SKILL.md)：海报版式。

这些入口不能统一等同于调用图像模型生图。先确定要可修改页面还是最终图片。

<a id="slides"></a>
## 演示文稿

- [deck-swiss-international](../skills/deck/deck-swiss-international/SKILL.md)：瑞士风格 HTML 演示。
- [frontend-slides](../skills/deck/frontend-slides/SKILL.md)：当前是简介入口；完整能力需要上游安装。
- PPTX 相关条目见 [演示文稿目录](../CATALOG.md#deck)，逐项确认包内内容和实际输出格式。

不要把 HTML、逐页图片或 PDF 描述为可编辑 PPTX。

<a id="system"></a>
## 设计系统

- [reference-design-contract](../skills/design-system/reference-design-contract/SKILL.md)：根据参考材料整理设计方向与规范。
- [design-brief](../skills/design-system/design-brief/SKILL.md)：梳理设计简报；正文提及 OpenDesign 设计系统来源。
- `ui-ux-pro-max` 当前仅简介，没有完整搜索数据与脚本。

输入应包含品牌约束和参考材料；未知信息需要保留为待确认。

## 尚不适合直接当作独立技能安装的入口

`library-curator`、`od-next-media-inputs`、`brand-extract` 和 `ecommerce-image-workflow` 涉及 OpenDesign 专属接口或工作流。先读 [限制说明](compatibility.md)，不能仅通过复制目录就声称能用。
